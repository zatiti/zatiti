# Zatiti mark variants

Mark-only PNG exports generated with the built-in image-generation tool from
the approved Zatiti logo proposal. Dark, light, and mint versions are intended
for organization avatars and repository artwork. They are raster variants,
not a normalized vector master. The application icon has not been replaced.

## Generation prompts

### dark

Edit the supplied approved Zatiti logo into ONE standalone square mark-only asset. Faithfully preserve the exact interlocking rounded Z silhouette in the small app tiles in the lower row of the reference, including its two rounded diagonal interlocking ends and negative space; do not redesign it. Mark color solid ivory #FCFCFC; full-bleed square background solid charcoal #111111. Center the mark, occupying 56% of image width, with generous equal optical margins safe for circular avatar cropping. Output 1024x1024 square. Absolutely no wordmark, text, letters besides the Z symbol, labels, extra samples, frames, tile outline, rounded outer canvas corners, glow, bloom, shadows, lighting, gradients, textures, or 3D. Crisp flat two-color logo artwork only. Remove all glow from the reference.

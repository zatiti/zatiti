## Glossary for this report

- **Package**: one self-contained unit of Go (or, for the desktop, Dart)
  code owning one part of the product; the plan has 36.
- **Lane**: one independent stream of work, one package or fix, run by one
  agent in its own copy of the repository (a worktree).
- **Integration lead**: this session, which verifies and merges every lane.
- **Landing gate**: build, race detector, linter, module-wide tests, and a
  mutation check, run by the lead before a merge.
- **Mutation check**: break a key safety rule on purpose and confirm a
  named test fails, then restore the code exactly.
- **Registry**: the package that assembles all modules and routes calls;
  it must accept every module's declared operations exactly.
- **Descriptor drift**: modules declaring their operations differently
  from the frozen catalog (for example CLI tokens with the binary name).
- **Seam defect**: a mismatch between two packages that each passed their
  own tests against fakes.
- **Lease**: a machine-wide lock so only one heavy build or test run
  happens at a time; there are now two (commits/module-wide, and
  package race runs).
- **Session limit**: the account-wide usage cap that stops every agent
  when exhausted.
- **Serenity**: the founder's separate memory service that Zatiti's memory
  adapter talks to.
- **Revision 2 / revision 3**: versions of the frozen shared
  specification every package is generated from.

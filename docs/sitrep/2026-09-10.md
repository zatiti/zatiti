## Glossary for this report

- **Worktree**: an isolated copy of the repo where one package's work
  happens without touching main.
- **Lane**: one independent stream of work (a package, owned by one agent).
- **Landing gate**: the integration session's verification checklist a
  package must pass before merging to main.
- **Mutation check**: disable a package's key safety fence, confirm a named
  test fails for the right reason, restore the code exactly.
- **Build lease (R-build-lease)**: a machine-wide lock so at most one heavy
  compile/test run happens at a time on this laptop.
- **Wave**: one batch of packages dispatched together.
- **Resume agent**: a fresh agent continuing a lane whose predecessor died.
- **In-process subagent**: an agent living inside this session (invisible
  to the OS process table; stopped via the harness, not `kill`).
- **ff-merge**: fast-forward merge — main moves to the branch's commit with
  no merge commit.
- **packages.json**: the frozen list of 37 planned packages the RFC is
  implemented against.

## Glossary for this report

- **wave:** one batch of plan tasks dispatched together, capped at 8 parallel agent sessions
- **claim:** one session locking a task to itself so others don't duplicate it
- **coordination gate:** a human task that records owner sign-offs in GitHub issues before code starts
- **contract revision 21:** the spec change that makes AI-model tool calls map to typed operations
- **ferro:** the public Go library this plan imports; its page scripts are vendored (copied verbatim, hash-pinned) into the extension
- **loopback:** the machine's own address (127.0.0.1) — the extension may only talk to the controller there, never to a hostname
- **vendored:** copied byte-for-byte from another repo with recorded hashes, never edited locally

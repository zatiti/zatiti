## Glossary for this report

- **Package root**: one directory the frozen plan treats as a unit of work; there are 36.
- **Lane**: one independent stream of work, run by one agent session in its own copy of the repository.
- **Landing gate**: build, race detector, linter, whole-module test suite, and a mutation check, all run by me before a merge.
- **Mutation check**: deliberately break a safety rule and confirm a named test fails, then restore the code exactly.
- **Descriptor**: a module's declaration of one operation — its name, version, schemas, scope, and who may call it.
- **Registry**: the component that assembles every module and routes calls; it must accept each module's declarations exactly.
- **Seam defect**: a mismatch between two packages that each passed their own tests against stand-ins.
- **Lease**: a machine-wide lock so only one heavy build or test run happens at a time; there are two.
- **Model Context Protocol**: the standard that lets other AI tools call Zatiti's operations as tools.
- **Serenity**: your separate memory service, which Zatiti's memory adapter talks to.
- **Revision 2 / revision 3**: versions of the frozen shared specification every package is generated from.
